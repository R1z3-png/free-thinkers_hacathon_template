# Готовые сборки

APK публикуются в [GitHub Releases](https://github.com/R1z3-png/free-thinkers_hacathon_template/releases), а не в Git-истории: сборка с моделями занимает около 758 МБ.

Для каждого релиза указываются версия, поддерживаемые ABI и краткий список изменений. Файл APK содержит модели и готов к установке на Android-устройство.
